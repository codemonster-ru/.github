# CodeMonster

We build open-source tools for web applications and documentation sites.

## Projects

- **[CodeMonster UI](https://github.com/codemonster-ru/ui)** — a design system for Vue 3 and
  server-rendered HTML. Build forms, navigation, and application layouts with shared design
  tokens and CSS. Plain HTML can opt into interactive behavior as needed.
  [Documentation](https://github.com/codemonster-ru/ui/blob/main/docs/index.md) ·
  [Local showcases](https://github.com/codemonster-ru/ui#preview-locally)

- **[Annabel](https://github.com/codemonster-ru/annabel)** — a lightweight PHP framework for
  building web applications.
  [Getting started](https://docs.codemonster.net/annabel/getting-started) ·
  [Starter project](https://github.com/codemonster-ru/annabel-skeleton)

- **[Vue SSG](https://github.com/codemonster-ru/vue-ssg)** — a Vue runtime and scaffolding CLI
  for building static sites from Markdown.
  [Packages and commands](https://github.com/codemonster-ru/vue-ssg/blob/main/README.md)

## Server-side rendering

Use [SSR Service](https://github.com/codemonster-ru/ssr-service) to render JavaScript
components on Node.js with Vite, and [SSR Bridge](https://github.com/codemonster-ru/ssr-bridge)
to call the renderer from PHP.

For existing VueForge projects, see the
[migration guide to CodeMonster UI](https://github.com/codemonster-ru/ui/blob/main/docs/migrate-from-vueforge.md).

For questions, feature requests, or bug reports, open an issue in the relevant repository.
